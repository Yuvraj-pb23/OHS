1️⃣ Clone the project
git clone <your-repo-url>
cd OHS

2️⃣ Create & activate virtual environment
python3 -m venv env
source env/bin/activate


(Windows)

env\Scripts\activate

3️⃣ Install dependencies
pip install -r requirements.txt

4️⃣ Create database & tables (VERY IMPORTANT)
python manage.py migrate


This creates:

all tables

contenttypes

permissions

sessions

5️⃣ FLUSH database (guarantees clean state)

⚠️ This deletes data, not tables.

python manage.py flush


Type:

yes


👉 This step avoids:

duplicate usernames

contenttype conflicts

partial loads

6️⃣ Migrate again (recreate system rows)
python manage.py migrate

7️⃣ Load your project data (from data.json)
python manage.py loaddata data.json -v 3


You should see:

Installed XXX object(s) from 1 fixture(s)


❌ If you see IntegrityError → STOP (data.json is not clean)

8️⃣ Create admin access (LAST)
python manage.py createsuperuser


⚠️ Always create superuser AFTER loading data.

9️⃣ Run server & verify
python manage.py runserver


Open:

http://127.0.0.1:8000/admin/


Login → Data should be visible.
